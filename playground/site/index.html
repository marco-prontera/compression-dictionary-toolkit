See the actual protocol

Open DevTools → Network. Keep Disable cache unchecked and enable Preserve log. Filter by product-. Inspect Available-Dictionary, Content-Encoding, and Use-As-Dictionary. No dictionary headers are injected by the page.

Read the measurements correctly

Each visit uses fresh request URLs while retaining dictionary storage. Delivery order alternates. Ready time covers the preview document, loading, and rendering; resource time covers each fetch. Neither isolates decompression CPU time. Localhost timings are noisy.

Reloading the same version can use that version as its own base. Compare the first visit after a version change for update savings. Use a fresh browser profile for a cold visit. This product uses synthetic catalog and CSS data.
